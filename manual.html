📰 新聞メーカー 説明書

XMLとCSSを「文字で書く」だけで新聞をつくり、PDFにして保存できるツールです。

1. 基本の使い方

  1. shinbun.html をブラウザで開く(ネット接続が必要です。Chrome / Edge などで直接開くのがおすすめ)。
  2. 左のファイル一覧から news.xml(紙面)や style.css(見た目)を開いて、文字で書く。
  3. パソコンでは、右に紙面(A4)がリアルタイムで表示されます。スマホでは「プレビュー」ボタンで表示します(Ctrl+Enter でも可)。
  4. PNG保存 / PDF保存 で、A4・1枚の印刷用データを保存。保存されないときは、出てくる画面の「保存」ボタン、または画像の長押しを使ってください。

紙面はA4縦に固定されています(印刷用)。内容がA4からはみ出すと、画面下に赤い警告が出ます。はみ出した部分は印刷されません。

XMLエディタで < を打つと、使えるタグが候補に出ます。CSSエディタでは . や # を打つと、XMLに書いたclass・id・タグ名が候補に出ます。

ファイル一覧の使い方

  • 新規:上の入力欄にファイル名(例 page2.xml)を書いて ＋。
  • 編集:ファイル名をクリックすると中身を編集できます。自動で保存されます(Ctrl+S でも可)。
  • 削除:🗑 を押し、「本当に?」と出たらもう一度押す(3秒以内)。
  • 紙面になるXML:最後に開いた .xml ファイルが紙面になります(「紙面」の印が付きます)。.css は全部まとめて適用されます。
  • 📁 フォルダ:フォルダ内のxml・css・js・画像などをまとめて読み込みます。PCのChrome/Edgeでは、フォルダを開いたまま直接編集・追加・削除でき、自動でフォルダに保存されます(File System Access API)。スマホやアプリ内ビューアでは「読み込みのみ」になり、読み込んだ内容はブラウザ内に保存されます。
  • 📄 ファイル:ファイルを複数選んで追加します(スマホ向け)。選んだ最初のXMLが紙面になります。画像が images/ に入っていなくても、ファイル名が同じなら src で見つかります。
  • 💾 / 📂:全ファイルを1つのJSONに保存/読み込み(バックアップ用)。スマホなどフォルダが使えない環境の保管場所になります。

フォルダを開いていないときは、ファイルはそのブラウザの中(IndexedDB)に保存されます。ブラウザのデータを消すと消えるので、大事なものは 💾 で保存してください。

2. XMLの書き方ルール

  • 最初のタグ(ルート)は1つだけ。ふつうは <newspaper> で全体を囲みます。
  • タグは必ず閉じます。<p>文</p>。中身のないタグは <img src="..."/> のように /> で閉じます。
  • 属性の値は "..." で囲みます。
  • 文字の & は &amp;、< は &lt; と書きます(エラーになったら確認)。
  • エラーのときは、画面下の赤いバーに理由が出ます。

3. class / id / style / script

class:どのタグにも、タグ名と同じclassが自動で付きます。<headline> は CSSで .headline と書けます。自分のclassも足せます。

<article class="top hot" id="a1">…</article>

/* CSS */
.article{ ... }   /* タグ名のclass */
.top{ ... }       /* 自分のclass */
#a1{ ... }        /* id */
.top .headline{ ... }

style:XMLの中に <style> を書くと、その場でCSSを足せます。CDATA で囲むと > や & をそのまま書けます。

<style><![CDATA[
  #a1 .headline{ color:#b00; }
]]></style>

script:<script> の中身はJavaScriptとして紙面で実行されます。document を使って紙面ぜんぶを読み書きできるので、全てを制御できるのはscriptタグです。

<script><![CDATA[
  document.querySelector('.top .headline').textContent = '新しい見出し';
  document.querySelectorAll('.p').forEach(p => p.style.fontSize = '18px');
]]></script>

scriptのエラーは、プレビューを閉じたあと画面下の赤いバーに表示されます。

4. 日付・時刻タグ

<date> と <time> は、タグの中身が書式になります。毎秒自動で更新され、編集はこのタグの中だけで完結します。

書式意味書式意味
YYYY年(2026)HH時(2桁 09)
M月(1〜12)H時(9)
D日(1〜31)mm分(2桁)
ddd曜日(月)ss秒(2桁)
<date>YYYY年M月D日(ddd)</date>  →  2026年10月21日(水)
<time>HH:mm:ss</time>           →  14:05:09

固定の日付にしたいときは、書式の文字を使わずに <date>昭和の日</date> のように書きます。

5. 画像(imgタグ)

  1. 左の 🖼 画像追加 で画像を選ぶ(複数OK)。images/ フォルダに入ります(大きい画像は自動で縮小)。
  2. 一覧の画像をタップすると、XMLのカーソル位置に <img src="images/○○.png" alt=""/> が入ります。
  3. 画像は一覧から削除(🗑)もできます。
<img src="images/photo.png" alt="写真" width="300"/>
<figure>
  <img src="images/photo.png" alt=""/>
  <caption>写真説明</caption>
</figure>

CSSの背景画像も同じ名前で指定できます:background:url(images/photo.png)

外部URL(https://...)の画像も使えますが、相手のサーバーが許可していないとPNG/PDFに写らないことがあります。確実なのは「画像追加」です。

7. PNG / PDF について

  • どちらもA4縦1枚(PNGは2382×3369px、PDFはA4サイズ)で、印刷向けです。
  • 紙面を画像にして保存するため、PDFの文字は選択・検索できません(日本語フォントをそのまま使うためです)。
  • 紙面の比率(A4)は固定です。複数ページには分かれません。はみ出さないよう、文字や画像の大きさを調整してください。
  • PNG/PDFは scriptが動いたあとの状態で保存されます。
  • アプリ内ビューアなど、ダウンロードが禁止されている環境では、自動保存されないことがあります。その場合は表示される画面の「保存」ボタンか「共有」、または画像の長押しを使うか、ファイルをChromeなどで直接開いてください。

8. よく使うCSS例

/* 2段組みにする */
.columns{ column-count:2; column-gap:20px; }
/* 横に3つ並べる */
.grid{ display:grid; grid-template-columns:repeat(3,1fr); gap:14px; }
/* 見出しの飾り */
.headline{ border-bottom:3px solid #222; }
/* 縦書き */
.vertical{ writing-mode:vertical-rl; }
